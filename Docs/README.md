## Qual documento usar

- Para a descrição consolidada e atual, use o DOCX em `01_TCC`.
- Para o banco de dados atual, use `02_Banco_de_Dados/DatabaseModel.md`. Os arquivos em `Versoes_anteriores` estão desatualizados e não representam o esquema atual.
- O PDF em `03_Prototipos/Referencias` é uma referência visual antiga; o protótipo reverso atual está no PDF ao lado e nas imagens individuais.
- Os arquivos `Visao_Geral_Anterior.md` e `Visao_Tecnica_Anterior.md` são registros antigos, preservados para consulta, não a fonte principal atual.
